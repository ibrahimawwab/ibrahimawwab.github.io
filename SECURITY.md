# Security Policy

## Scope

This policy applies to the source files and website content in this repository, `ibrahimawwab.github.io`.

The site is a static professional information page. It does not intentionally collect visitor accounts, passwords or payment information.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue.

Send a concise report to **ibrahimawwab@proton.me** with:
- A description of the suspected vulnerability
- The affected URL or file
- Steps to reproduce, if safe to provide
- Potential impact and supporting evidence

Do not include other people's personal data, credentials or secrets in a report.

## Response

Reports will be reviewed as reasonably practicable. Acknowledgment and remediation timelines depend on severity, reproducibility and the ability to validate the report. Please allow time for investigation before public disclosure.

## Supported content

The policy covers the current default-branch version of the website source. As this repository currently contains a small static site and no application dependency stack, version-based security support is not applicable.

## Safe testing

Only test systems and accounts you own or have explicit authorization to assess. Avoid denial-of-service testing, destructive actions and access to other users' data.
